# 原版画风与宠物逐帧制作流程

用户选择 `assets/pet-style-v4/reference-sleepy.png` 中圆润、紧凑的小体型与坐姿抱尾效果。原画沿用璃芽的Q版比例、衣服、银白卷发、青绿角与金色眼睛。

全部15种情绪各自生成8个连续绘制的动作姿势。眨眼、表情、头部、手、头发和尾巴都由实际动作帧体现；困倦状态保留坐姿抱尾，其他状态使用原来的小体型站姿及一条低位尾巴。

## 实际采用的宠物制作步骤

使用内置图像工具逐状态生成纯品红背景动作条，源图和精确提示词分别保存于 `assets/pet-style-v4/decoded/`、`prompts/`。不直接让生成器绘制完整图集。

`scripts/qq_pet_frames.py` 调用宠物制作技能随附的实际脚本入口：

1. `extract_strip_frames.py`：按连通区域提取八个完整姿势，采用行内共享缩放与基线，拒绝靠机械等分掩盖缺帧。
2. `compose_atlas.py`：确定性组装精确的192×208帧格。
3. `despill_chroma_edges.py`：每行只进行一次边缘色溢清理，保留透明度。
4. `inspect_frames.py`：检查帧数、完整性、边缘、色键残留与异常缩放。
5. `render_animation_previews.py`：从这些实际帧编码GIF，使用动作与停顿的帧时长。

原参考中的额外左尾会在生成动作条时明确删除；有重复尾巴、造型变高或动作错误的整行重新修正并复查。小的背景碎屑若由连通提帧正确排除，保留通过的主体，不为已解决的背景问题重新设计角色。

QQ的15种表情名称与帧数通过适配器传给这些脚本。最终是8列×15行的自定义QQ图集，不是ChatGPT Pet v2的11行格式，不创建、切换或上传到宠物服务。

## 重建与交付

```powershell
./.venv-artwork/Scripts/python.exe -m pip install -r scripts/requirements-pet-artwork.txt
# 每条生成动作条完成后立即取帧、检查和预览，例如：
./.venv-artwork/Scripts/python.exe scripts/qq_pet_frames.py sleepy
# 所有15条通过后统一组装并替换本地素材：
./.venv-artwork/Scripts/python.exe scripts/assemble_pet_style_set.py
```

当前已按[统一配色记录](11统一配色.md)对其余14条动作条做仅颜色修正，保留原版抱尾配色基准；整个图集、GIF与静态图使用同一份色表。最终GIF从已编码图集重新取帧后生成。`assets/expressions/` 和 `src/liya_companion/assets/` 的15种同名GIF、PNG与合辑同步；原先的变形动画保留在历史归档，不再作为当前预览。

每种表情有 8 张原画。GIF 导出时用相邻原画估算局部位移，加入过渡帧，每种表情共 19 至 22 帧。普通状态约 1 秒循环，困倦状态约 1.3 秒。每张原画的像素和出场时间均在导出后逐一验证。
