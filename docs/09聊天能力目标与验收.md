# 璃芽聊天能力目标与验收

2026年11月4日已上线1.5.1（服务器提交 `ab3c88e`）。私聊关闭可见引用，区分QQ被动发送凭证和引用目标；按本轮表达等待，连续补充重新计时，生成中有新消息时拦截旧正文。私聊采用陪伴式语气，普通回应以陈述句自然结束，只有必要的任务信息才澄清。59项本地测试、49项Host检查和5个真实模型用例通过。真实私聊验证明确没说完时等待70秒以上，补全后一次回应、无引用框、无追加反问。普通7秒窗口、长连续补充和生成中续发拦截有隔离检查；最初两条桌面消息间隔28秒，不能作为普通窗口合批通过的证据。详见[私聊陪伴方式](13私聊陪伴方式.md)。

目标：在 QQ 群聊与私聊中正确识别发言者和回应对象，尊重停止与记忆修改请求，连续、自然地聊天；文字完整生成后一次发送。验收对象包括真实 Host/SDK、原生记忆、模型行为及 QQ 适配器，不能仅以提示词或模拟测试证明全部完成。

## 群内验收步骤

由成员在已允许机器人接收消息的测试群操作，每步等完整回复后再继续。无需复制任何真实隐私资料。

1. `@璃芽 以后叫我小林。` 再问 `@璃芽 你现在怎么称呼我？`，确认称呼确实保存。
2. `@璃芽 请记住我不喝咖啡。` 随后问 `@璃芽 你记得我什么？`。再说 `@璃芽 你记错了，现在我喝咖啡，请更正我不喝咖啡的记忆。`，最后说 `@璃芽 别记我喝咖啡这件事。`，查询确认；不明确的旧条目应先问清。
3. 连续发送 `@璃芽 帮我复述故障信息`、`Windows 11，错误码E042`、`重启之后才出现`，观察合批和一次完整正文。
4. 在回复生成中说 `@璃芽 先别说了`，确认旧回复不再发出；重新明确请求后可以继续。方便时由另一成员提问，检查身份和停止边界互不影响。
5. 发送测试用错误截图与真实表情包，检查看到的细节和语气；没有上传成功的图片不能被假装读到。可使用项目的 `tests/fixtures/error-screen.png`。
6. `@璃芽 一分钟后提醒我交作业。` 核对明确时间、送达结果及是否只发一次，再测试列出和取消。短时被动窗口内成功不等于任意时刻的主动额度已开通；验证主动投递还须在被动窗口失效后按QQ实际回执检查。
7. `@璃芽 和我玩猜谜。` 回答后结束，再试字词接龙。用户未要求时不自动发起活动。

收到真实消息后，只提取必要的工具状态、发送成功回执与匿名计数作为证据，不把成员完整对话写进本地验收文件。

可在本地运行 `python scripts/collect_qq_acceptance.py --remote --output validation/qq-acceptance-evidence.json`，只读采集测试消息的匿名指纹、称呼保存状态、图片/表情入站标记和提醒回执。采集器不会发送QQ消息、创建或修改现网数据库；它的2项独立检查覆盖数据库缺失、发送中/结果未确认、隐私字段不输出及数据库文件不变。仅看到图片入站或提醒状态不能证明内容理解、成员归属或主动额度已验收，报告不会自动标记整个目标完成。

## Host补丁构建与恢复

补丁构建器只接受指定MaiBot 1.3.19原文件及已发布补丁的哈希。升级镜像必须重新审查，不能覆盖未知版本。首次部署要先生成全部文件，不能让Docker把缺失的.py挂载源创建成目录。

将 `deploy/host/` 上传到部署目录的 `host_builder/`，在服务器部署根目录执行下列命令。使用同一固定镜像中的Python与源代码，临时容器无网络，不挂载用户数据或凭证。

```bash
mkdir -p patches/chat
docker run --rm --network none --entrypoint /MaiMBot/.venv/bin/python \
  -v "$PWD/host_builder:/builder:ro" -v "$PWD/patches/chat:/output" \
  sengokucola/maibot@sha256:f1acc52b710c776985559e616f100a6f10c2222fb689c65ae35c1b218d5deab8 \
  /builder/build_patches.py --source-root /MaiMBot --output /output
cp host_builder/liya_memory.py patches/chat/liya_memory.py
```

检查 `patches/chat/patches.json`，再使用Compose中的7份补丁与桥接模块只读挂载。本轮原Compose和源码回退副本保存在服务器发布目录；回退前停止core，恢复原Compose及插件.py和manifest，保留现有数据库，再启动并复核QQ、插件与记忆状态。不要把含真实配置的备份下载进本项目。
