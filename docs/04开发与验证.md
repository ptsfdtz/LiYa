# 璃芽开发与验证

陪伴功能是使用公开 MaiBot SDK 的独立插件。运行源码位于 [src/liya_companion](../src/liya_companion/)，其中 plugin.py 负责钩子和发送，state.py 负责持久化与状态演算；原生记忆兼容补丁另放在 deploy/patches。

## 修改位置

| 需求 | 文件 |
| --- | --- |
| 修改语气、偏好与群私聊行为 | design/liya-personality-v2.json，并同步原生人格配置 |
| 修改熟悉程度、心情衰减与信任规则 | src/liya_companion/state.py |
| 修改事件分类、注入时机、表情发送规则 | src/liya_companion/plugin.py |
| 修改运行开关与自动表情冷却 | WebUI 陪伴插件配置 |
| 替换 GIF | assets/expressions 与 src/liya_companion/assets 同名文件 |
| 修改镜像、挂载、端口与日志策略 | deploy/compose.example.yaml 与服务器实际 compose.yaml |

当前 _manifest.json 声明 llm.generate 和 send.emoji 能力。新增 SDK 调用时需核对能力声明；SDK 未授予的能力不会因代码写好而可用。插件不依赖导入 MaiBot 的 src；契约测试会导入原生类，以验证与部署版本的兼容性。

## 状态单元测试

在本地项目根目录执行，不依赖 QQ 或模型服务。

```powershell
python -m unittest discover -s src/liya_companion -p test_state.py -v
```

当前4项检查覆盖消息去重和防刷、群私聊与成员隔离、心情重启保存和时间衰减、数值边界与幂等性。

## 原生契约测试

需要 MaiBot 1.3.19 运行环境和当前 SDK。先将测试复制到服务器，再在容器中执行；测试使用临时数据库及模拟模型和发送器，不向群里发消息。

```powershell
scp .\tests\test_hooks.py marsIntranet:/opt/dragon-maibot/test_liya_hooks.py
ssh marsIntranet
```

```bash
docker cp /opt/dragon-maibot/test_liya_hooks.py dragon-maibot:/tmp/test_liya_hooks.py
docker exec -w /MaiMBot -e PYTHONPATH=/MaiMBot dragon-maibot \
  /MaiMBot/.venv/bin/python /tmp/test_liya_hooks.py -v
```

当前8项检查覆盖原生 Context Item、完整参数保留、分类去重、文字处理标志、配置控件状态、一次性表情发送、显式表情工具参数及冷却，以及只有工具调用的规划回合也更新心情。补处理测试确认只更新状态、不发送消息。

## 部署修改

修改前运行服务器备份。只同步需要的插件源码或素材，保留服务器 config.toml、独立 Git 历史和 data 下数据库。插件源码提交到服务器现有独立仓库后重启 core，检查加载失败数、QQ 连接和记忆就绪状态。改人格也要同步实际启用档案，单独修改本地 JSON 不会自动改变现网。

```powershell
scp .\src\liya_companion\plugin.py .\src\liya_companion\state.py marsIntranet:/opt/dragon-maibot/plugins/liya_companion/
```

## 已修复的问题

1. modified_kwargs 替换整组参数：保留原生 payload 中所有未修改字段，避免 item_schema_version 等信息丢失。
2. 配置控件状态必须覆盖全部已声明控件：状态、模型自检和补处理控件均返回对应状态。
3. SQLite 连接在上下文退出后显式关闭，避免连接资源累积。
4. 仅在 Replyer 评估会漏掉直接调用工具的回合：1.0.1 将评估提前至 Planner，共享锁和消息去重；提供未评估消息补处理入口。
5. 原生记忆 JSON metadata 的聊天范围解析：通过固定镜像下的最小兼容补丁修复，单独记录版本及回归证据。

## 升级顺序

先备份配置和数据，再在隔离环境中核对目标镜像、SDK 契约和原生补丁。验证状态单元测试、钩子契约测试、记忆同聊天检索及跨聊天零命中，再验证 QQ 文字和 GIF 收发。最后核对重启保留与自动重连。用实际部署的固定版本完成验证后，再更新文档、manifest 和镜像摘要。

开发文档入口为 [MaiBot SDK](https://github.com/Mai-with-u/maibot-plugin-sdk/blob/main/docs/guide.md)。本目录不新增依赖锁文件；源码测试与运行版本以现网镜像和 manifest 的范围为准。
