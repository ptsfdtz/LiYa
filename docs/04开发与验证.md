# 璃芽开发与验证

1.5.1当前验证为59项本地测试、49项Host/SDK检查及5个私聊真实模型用例。新增私聊连续补充、未完表达等待、生成中续发拦截和QQ无引用发送检查；保留必要澄清。真实私聊证明明确等待后一次回应，普通7秒窗口仍以隔离检查为证。见[私聊陪伴方式](13私聊陪伴方式.md)。

1.5.0新增`experiences.py`：保存有来源的共同经历、词语索引和当前成员召回。当前本地测试59项、服务器隔离Host/SDK检查42项均通过，另有4项真实模型验收。新功能及测试、发布命令见[共同经历与情绪记忆](12共同经历与情绪记忆.md)；下文的48项与37项为1.4.x历史基线。

陪伴功能是使用公开 MaiBot SDK 的独立插件。运行源码位于 [src/liya_companion](../src/liya_companion/)，其中 plugin.py 负责钩子和发送，state.py 负责持久化与状态演算；原生记忆兼容补丁另放在 deploy/patches。

当前 _manifest.json 声明 llm.generate、send.emoji、send.text 和 liya.memory 能力。前三项是SDK能力；liya.memory是本部署通过Host注册的专用能力，桥接实现与严格版本校验构建器位于 `deploy/host/`。Runner插件仍不导入MaiBot的src。Host补丁补齐人物画像聊天范围、固定工具身份上下文、延长提及合批上限及回复生成失败说明。构建器只接受已核对的原始或补丁哈希，不能直接用于未知升级版本。

## 1.4.0完整验收入口

`python -m unittest discover -s src/liya_companion -p test_*.py -v` 当前运行48项本地测试。

`python scripts/check_chat_runtime.py --approved-assets` 把当前代码复制到现网容器的独立临时目录，使用现网已发布素材。当前37项Host/SDK/记忆内核和采集器检查中36通过，1项未发布素材检查跳过。不会修改现网配置或向QQ发送消息。原生记忆测试使用临时数据库、配置中的真实嵌入服务以及合成成员标识。

附加 `--models` 运行当前23个真实模型场景，包括自然语言工具选择、话题状态更新、正文风格、缺失图片说明和真实截图、表情包输入。原1.4.0的22个场景见[基线模型结果](../validation/chat-model-results.json)。1.4.1新增相对提醒用例可用 `--models --model-case R01_relative_minute` 单独执行，结果为 `model-behavior-selected-results.json`，见[相对提醒结果](../validation/relative-reminder-model-results.json)。这类抽样证明所列场景，不保证任意自然语言输入都不会出错。

`prepare_chat_release.py` 和 `activate_chat_release.py` 是本次1.3.1到1.4.0的固定基线发布脚本，修改前检查旧文件哈希和Git状态、备份，保留数据与素材；不作为通用升级器直接重跑。`verify_chat_release.py` 只读核对运行状态、Host只读挂载、源码与素材哈希、数据库完整性，不输出凭证或用户消息。

## 部署修改

## 已修复的问题

1. modified_kwargs 替换整组参数：保留原生 payload 中所有未修改字段，避免 item_schema_version 等信息丢失。
2. 配置控件状态必须覆盖全部已声明控件：状态、模型自检和补处理控件均返回对应状态。
3. SQLite 连接在上下文退出后显式关闭，避免连接资源累积。
4. 仅在 Replyer 评估会漏掉直接调用工具的回合：1.0.1 将评估提前至 Planner，共享锁和消息去重；提供未评估消息补处理入口。
5. 原生记忆 JSON metadata 的聊天范围解析：通过固定镜像下的最小兼容补丁修复，单独记录版本及回归证据。

## 升级顺序

先备份配置和数据，再在隔离环境中核对目标镜像、SDK 契约和原生补丁。验证状态单元测试、钩子契约测试、记忆同聊天检索及跨聊天零命中，再验证 QQ 文字和 GIF 收发。最后核对重启保留与自动重连。用实际部署的固定版本完成验证后，再更新文档、manifest 和镜像摘要。

开发文档入口为 [MaiBot SDK](https://github.com/Mai-with-u/maibot-plugin-sdk/blob/main/docs/guide.md)。本目录不新增依赖锁文件；源码测试与运行版本以现网镜像和 manifest 的范围为准。
