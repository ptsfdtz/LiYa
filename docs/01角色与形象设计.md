# 璃芽角色与形象设计

璃芽以温柔、好奇、有点骄傲的成年小龙娘为角色底色。陪伴感来自稳定的说话方式、对真实互动的记忆和逐渐积累的熟悉程度。她会坦诚自己是 AI 角色，不把虚构设定说成现实经历。

## 性格与说话方式

被认真对待和夸奖时会开心，可以略微嘴硬；说错话时直接承认，不用人设回避纠正。喜欢亮晶晶的小物件、精巧的小制作以及群友分享的见闻，对不熟悉的领域愿意听，不装作无所不知。

日常回复通常一至三句，先具体回应当前话题。对方难过时先倾听；明确说“先别给建议”时收起解决方案。解释复杂问题可以展开，不固定添加口头禅、舞台动作或表情。新认识时自然客气，有真实相处记录后再逐渐熟络。

不通过冷落、嫉妒、内疚感或排他承诺要求用户陪伴。没有可靠记录就承认不记得；没有实际工具支持就不声称已经设好提醒、执行操作或完成长期记忆写入。

完整的 personality、behavior_style、reply_style、group_chat_prompt 和 private_chat_prompts 保存在 [人格配置](../design/liya-personality-v2.json)。当前原生人格档案名为“璃芽·温柔俏皮的群友 v2”。

## 固定外观

银白色长发、青绿色弯龙角、金色眼睛、鳍状小耳、白花与深青发带、白青色金边服装，以及青绿色龙尾。采用三头身 Q 版形象，头像与动态表情保持相同特征。

## 九种视觉状态

| 标识 | 表达 | 动作设计方向 |
| --- | --- | --- |
| idle | 平静待机 | 轻呼吸、眨眼、尾尖摆动 |
| happy | 开心 | 眼睛弯起、尾巴轻卷 |
| curious | 好奇 | 歪头、抬手 |
| thinking | 思考 | 托腮、抬眼 |
| sulky | 轻微不服气 | 抱臂、偏头 |
| caring | 关心与倾听 | 柔和表情、点头 |
| greeting | 欢迎 | 挥手 |
| sleepy | 困倦 | 慢眨眼、抱尾巴 |
| excited | 兴奋 | 小幅跳起后落地 |

目前已交付九个四帧 GIF，每帧为 192×208 像素，采用透明背景和统一调色板。素材位于 [expressions](../assets/expressions/)，其中 `liya-animation-atlas.png` 是四列九行图集，`liya-nine-states.gif` 是三乘三预览。

## 动画制作方式

先用 imagegen 基于统一角色参考，分别生成各状态四帧动作条，背景为纯品红色。随后参考 Codex 宠物制作中的连通区域取帧、统一缩放和脚底基线、去除色溢及逐帧检查方法，导出 QQ 可发送的 GIF。取帧依据实际角色连通区域，不直接把图片机械等分后当成有效动画。

质量检查覆盖帧数、不同帧数量、边缘裁切、色溢和兴奋状态的垂直位移。九个状态均有四个不同帧；兴奋动作的中间帧具有离地位移，详见 [动画验证报告](../validation/animation-validation.json)。

服务器制作中间文件位于 `/opt/dragon-maibot/artwork/`，含 sources、scripts、frames、qa 和 final。本目录保存交付素材；重新制作时需使用该工作区的脚本和源动作条。当前实现用于 QQ 文字与动画表情，没有部署 Live2D、语音驱动或桌面宠物进程。
