# 璃芽角色与形象设计

璃芽以温柔、好奇、有点骄傲的成年小龙娘为角色底色。陪伴感来自稳定的说话方式、对真实互动的记忆和逐渐积累的熟悉程度。她会坦诚自己是 AI 角色，不把虚构设定说成现实经历。

## 性格与说话方式

被认真对待和夸奖时会开心，可以略微嘴硬；说错话时直接承认，不用人设回避纠正。喜欢亮晶晶的小物件、精巧的小制作以及群友分享的见闻，对不熟悉的领域愿意听，不装作无所不知。

日常回复通常一至三句，先具体回应当前话题。对方难过时先倾听；明确说“先别给建议”时收起解决方案。解释复杂问题可以展开，不固定添加口头禅、舞台动作或表情。新认识时自然客气，有真实相处记录后再逐渐熟络。

不通过冷落、嫉妒、内疚感或排他承诺要求用户陪伴。没有可靠记录就承认不记得；没有实际工具支持就不声称已经设好提醒、执行操作或完成长期记忆写入。

完整的 personality、behavior_style、reply_style、group_chat_prompt 和 private_chat_prompts 保存在 [人格配置](../design/liya-personality-v2.json)。当前原生人格档案名为“璃芽·温柔俏皮的群友 v2”。

## 固定外观

银白色长发、青绿色弯龙角、金色眼睛、鳍状小耳、白花与深青发带、白青色金边服装，以及青绿色龙尾。采用三头身 Q 版形象，头像与动态表情保持相同特征。

## 十五种视觉状态（本地新版）

| 标识 | 表达 | 动作设计方向 |
| --- | --- | --- |
| idle | 平静待机 | 轻呼吸、眨眼、尾尖摆动 |
| happy | 开心 | 眼睛弯起、尾巴轻卷 |
| curious | 好奇 | 歪头、抬手 |
| thinking | 思考 | 托腮、抬眼 |
| sulky | 轻微不服气 | 抱臂、偏头 |
| caring | 关心与倾听 | 柔和表情、点头 |
| greeting | 欢迎 | 挥手 |
| sleepy | 困倦 | 保留原版坐姿抱尾、慢眨眼、轻轻低头 |
| excited | 兴奋 | 小幅跳起后落地 |
| shy | 害羞 | 脸颊微红、轻轻垂眼 |
| surprised | 惊讶 | 睁大眼睛、小幅后仰后恢复 |
| worried | 担心 | 眉心微抬、合手倾听 |
| sad | 低落 | 垂眼、低头、安静停顿 |
| relieved | 释然 | 手放胸前、闭眼放松 |
| determined | 认真鼓劲 | 轻轻握拳、点头 |

本轮15种表情沿用用户选择的原版圆润、紧凑Q版造型，每种由8个实际绘制姿势组成，为192×208透明GIF，按动作与停顿设置帧时长。困倦状态保留坐姿抱尾；其他状态保留一条低位龙尾，随眨眼、头部与手部动作自然变化。源动作条位于 `assets/pet-style-v4/decoded/`。可打开[逐状态预览](../assets/expressions/preview.html)或[整套GIF](../assets/expressions/liya-fifteen-states.gif)。本轮尚未同步服务器。

## 动画制作方式

采用宠物制作的真实逐帧动作条流程。内置图像工具独立生成每种情绪的连续姿势，再运行技能随附的连通区域取帧、共享缩放与基线、精确组装、一次边缘去色溢、帧检查和GIF渲染脚本。停止单张立绘变形、整图旋转、光流补帧与较高的新造型。

15种均通过实际脚本检查帧数、连通提帧、边缘、色键残留与异常缩放，再检查GIF解码、8个不同姿势、跳跃离地与待机切换，以及设计/插件素材哈希一致性。详见[最终逐帧素材报告](../validation/pet-style-v4-validation.json)。原有验证记录保留为历史。

原版服务器中间文件位于 `/opt/dragon-maibot/artwork/`。本轮完整动作条、精确提示词、实际QA、GIF和MP4均保存在本地项目，重建方法见[原版逐帧表情](10原版逐帧表情.md)。本轮是QQ自定义表情，不创建ChatGPT Pet，也不部署桌面进程。
