# 璃芽：原版画风的逐帧表情

本轮以用户提供的 `reference-sleepy.png`（坐着抱尾的原版璃芽）锁定画风。用户要求保留这种圆润、紧凑的小体型；之前较高、较精细的新造型与单张图变形动画均已停用。

采用宠物制作的动作条流程，继续用于 QQ 自定义表情，不创建 ChatGPT Pet，也不需要十六个视线方向或宠物服务上传。

1. 素材准备：用户原图、原始状态表与原版单状态立绘。
2. 造型基准：先验收 `sleepy` 抱尾与 `idle` 单尾动作条。
3. 独立动作条：每种情绪由图像工具直接绘制8个连续姿势，眼睑、头部、手、头发和尾巴实际变化。
4. 统一取帧与验收：运行随宠物技能提供的连通区域取帧、共享缩放、组装、去色溢、逐帧检查和GIF预览脚本，再替换素材。

目录：`decoded/` 保存纯品红动作条，`prompts/` 保存完整生成提示词，`qa/rows/` 保存原始行、清洁行、帧与实际检查报告，`previews/` 保存逐帧GIF。`pipeline/` 是官方宠物脚本生成的准备参考；QQ的15种自定义状态通过 `scripts/qq_pet_frames.py` 适配名称与帧数，未声称该自定义图集符合 ChatGPT Pet v2 格式。

允许确定性处理背景、取帧、统一缩放和编码；禁止以单图拉伸、旋转、光流或凑帧替代实际绘制的动作。每状态播放节奏取决于真实动作帧和自然停顿，不沿用上一版“60帧20 FPS”的标注。
