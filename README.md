# 璃芽项目说明

璃芽是运行在 QQ 群中的 AI 小龙娘，采用 MaiBot、QQ 官方适配器和独立陪伴插件。当前版本已部署在 `10.249.254.57:/opt/dragon-maibot`；本目录保存设计、工作流程、部署参考、插件源码、形象素材和验收证据。

整理日期为 2026年11月4日，时区 Asia/Shanghai。当前陪伴插件为 1.4.1，服务器源码提交为 `ff10f55`。模型为 `gpt-6.1-sol`，推理档位 `low`；文字回复分配到支持原生联网的 `dragon-gpt-web`。

1.4.1修正相对提醒的整分取整问题：“一分钟后”按实际收消息时刻加60秒计算，超时不伪装成创建成功。46项本地测试和33项Host检查（32通过、1项素材检查跳过）通过，新增相对提醒真实模型用例通过。已完成称呼保存与短正文真实QQ收发，称呼在升级重启后仍保留；实际图片接收和提醒投递仍待验收。见[1.4.1现网检查](validation/release-1.4.1-validation.json)。

1.4.0 已部署成员与引用归属、停止回应、个人称呼与记忆管理、话题进展、持久提醒和轻量游戏，继续完整生成后一次发送正文。44项本地测试、30项Host检查（其中1项未发布表情素材检查跳过）及22个真实模型场景通过；QQ连接、记忆就绪、源码与挂载核对通过。新能力的真实QQ群入站、图片接收和提醒投递仍待成员发起验收，不能用隔离检查替代。见[聊天能力目标与验收](docs/09聊天能力目标与验收.md)和[1.4.0现网检查](validation/release-1.4.0-validation.json)。

已部署按需群聊简报，可整理当天、昨天、最近N条、最近若干小时或指定起止时段；联网检索在文字回复阶段按问题需要调用。原发布范围见[1.3.0部署记录](validation/release-1.3.0-validation.json)，使用方式见[群聊简报](docs/06群聊简报.md)与[联网检索](docs/08联网检索.md)。

1.3.1 修正空记录提示：只有总结请求时，明确说明接收范围设置及历史无法自动补齐。接收普通消息需要群主在手机QQ设置“获取群内全部消息”；服务器无法代替客户端授予这个权限。见[修正记录](validation/release-1.3.1-validation.json)。

用户调整手机QQ接收范围后，两条普通测试消息已入库；实际“最近10条”请求读取3条可用记录并成功发送简报，接收至发送的完整链路已验证。

本地全部15种情绪与表情 GIF 沿用原版圆润 Q 版逐帧动作，并已统一到原版抱尾图的配色：银白淡紫头发、低饱和青绿、象牙白和柔和金边。各状态保留8个实际动作帧，全部GIF共用同一份色表。见[原版逐帧表情](docs/10原版逐帧表情.md)与[统一配色记录](docs/11统一配色.md)，本轮素材尚未同步现网。

## 目录用途

```text
LiYa/
  README.md                    项目入口
  docs/                        设计、运行、部署、开发与验收说明
  design/                      人格与形象设计配置
  assets/                      头像、立绘、15状态GIF、源图集和动画预览
  src/liya_companion/           插件源码与运行素材，含本地待部署增强
  tests/                       针对 MaiBot 原生契约的集成测试
  deploy/                      Compose、备份脚本、脱敏配置与兼容补丁
  validation/                  结构化验收证据
  FILES.sha256                 本次整理的文件哈希
```

`src/liya_companion/assets/` 是插件运行所需的素材副本；`assets/expressions/` 供设计预览和后续创作使用。这里只保存可读配置模板，不包含实际 API Key、QQ AppSecret、聊天数据库、登录令牌、SSH 私钥或服务器备份包。

现网已经运行，不需要为了使用本目录重新部署。`deploy/compose.example.yaml` 应放在服务器部署目录根部使用；直接在本地 `deploy/` 下启动会挂载错误的数据位置。新服务器部署还需要 QQ 适配器、模型文件和管理员填写的真实凭证，步骤见部署文档。
